### **The Transformer Architecture**
The Transformer architecture has continued to dominate many areas in machine learning applications, most notably Natural Language Processing, which we are seeing here. While there are other ML libraries in Python that can implement a transformer from scratch, I decided to use JAX for accelerating computation backend, Flax (which already has the main components of the Transformer, Self Attention and Multi Head Attention, already integrated into it) for implementing neural networks, and Optax for optimizing the models. 

The transformer consists of input and output layers, that comprise of encoder-decoder stacks. Encoders are sequentially made of multi-head attention, followed by the feed-forward network. Decoders are sequentially made of masked multi-head attention, followed by cross-attention, and the feed-forward network. The transformer models in this repository only have token + positional embeddings and a stack of decoder blocks. 

This repository is focused on tuning the architecture of this basic transformer, such as the number of decoder blocks and number of parameters through increasing/decreasing the hidden size of the model, and techniques of optimizing the learning of the transformer. These experiments will then inform us how each experiment affects the accuracy of the optimized model on predicting the following character.
